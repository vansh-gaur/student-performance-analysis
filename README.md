# Student Performance Analysis

Analysis and prediction of student final scores from study habits and
academic history.

## Problem

Can a student's final score be predicted reasonably well from a small set
of study and academic variables, and which of those variables matter most?
This project works through the full pipeline: data generation, cleaning,
exploratory analysis, and model comparison.

## Dataset

The dataset is synthetic data generated for this project
(`generate_data.py`, fixed seed 42). It is not real student records.

- 500 rows, one per student
- Target: `final_score` (0-100)
- Features:

| Column | Description |
| --- | --- |
| `study_hours_per_week` | Hours spent studying per week |
| `attendance_percent` | Class attendance, percent |
| `previous_score` | Score in the previous assessment (0-100) |
| `sleep_hours` | Average sleep per night, hours |
| `assignments_completed_percent` | Assignments completed, percent |
| `social_media_hours_per_day` | Social media use per day, hours |

The target was built from a simple weighted combination of these features
plus random noise (standard deviation 7), so the relationships are
detectable but not exact. Summary statistics for the generated data:

- Mean final score: 70.5, standard deviation: 10.8
- Mean study hours per week: 15.0
- Mean attendance: 84.3%
- Mean previous score: 69.9

## Methods

1. `generate_data.py` creates `data/student_performance.csv`.
2. `clean_data.py` checks for missing values and duplicates, clips values
   to their valid ranges, and writes `data/student_performance_clean.csv`.
3. `explore.py` writes summary statistics and correlations to `reports/`
   and plots to `reports/figures/`.
4. `train.py` splits the data 80/20 (train/test, seed 42), trains three
   models with 5-fold cross-validation on the training set, and saves the
   best model by cross-validation RMSE to `models/`.
5. `predict.py` loads the saved model and predicts a final score for a
   single student.

Models compared: Linear Regression, Random Forest, Gradient Boosting.

## Results

Results from the actual run in this repository (test set, 100 students):

| Model | CV RMSE | Test RMSE | Test MAE | Test R2 |
| --- | --- | --- | --- | --- |
| Linear Regression | 6.955 | 7.421 | 6.035 | 0.575 |
| Random Forest | 7.481 | 7.745 | 6.185 | 0.537 |
| Gradient Boosting | 7.528 | 7.731 | 6.148 | 0.539 |

Linear Regression was the best model by cross-validation RMSE and is the
saved model. On the test set it explains about 58% of the variance in
final scores, with a typical error of around 7 points. That is a realistic
result for this kind of data, not a near-perfect prediction.

Correlations with final score:

| Feature | Correlation |
| --- | --- |
| Study hours per week | 0.608 |
| Previous score | 0.364 |
| Social media hours per day | -0.206 |
| Assignments completed | 0.183 |
| Attendance | 0.141 |
| Sleep hours | 0.132 |

Random Forest feature importance tells a similar story: study hours
(0.466) and previous score (0.192) matter most, followed by social media
use (0.098), sleep (0.084), assignments (0.083) and attendance (0.078).

Figures are in `reports/figures/`, including the final score
distribution, correlation heatmap, study hours vs final score, previous
score vs final score, and feature importance.

## How to run

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python generate_data.py
python clean_data.py
python explore.py
python train.py
```

The trained model file (`models/`) and the figures in
`reports/figures/` are generated by running the pipeline above, so they
are not committed to the repository — run `train.py` before `predict.py`.

Predict for a single student:

```bash
python predict.py --study-hours 20 --attendance 90 --previous-score 75 \
    --sleep 7 --assignments 85 --social-media 2
```

Running `predict.py` with no arguments uses a typical example student
(15 study hours, 85% attendance, previous score 70).

## Limitations and future improvements

- The data is synthetic, so conclusions do not transfer directly to real
  students. The relationships in the data are simple by construction.
- Only six features are used. Real performance also depends on factors
  not included here, such as subject difficulty, teaching quality, and
  prior background.
- The model explains roughly 58% of the variance on the test set. It is
  useful for exploring patterns, not for making decisions about
  individual students.
- Future work could use real (anonymised) data, add more features,
  try tuned models, and test how well the model generalises to a
  different cohort.
